# Five-a-Side

A 3D five-a-side football game for the browser, built with Three.js, Rapier and TypeScript.

```bash
npm install
npm run dev
```

Open http://localhost:5173. In the current scaffold, **Space** fires a random test shot
and **R** resets the ball to the centre spot.

See `CLAUDE.md` for the game design, architecture and roadmap.
